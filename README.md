## 口径说明

- **最低价**只统计有货报价，缺货的不算；0 元表示商家在做免费赠送，表里标为「免费」。
- **有货率** = 有货报价条数 ÷ 该商品全部在售报价条数。
- **低价带**是当日最便宜的 5 条报价的价格区间，用来判断最低价是孤例还是整片都便宜。
- 仓库只发布聚合口径，不含店铺名、单条报价标题和商家链接；实时逐条报价看站内商品页。
- 采集每小时一次，若上游当次快照被标记为 stale，本仓库跳过该次、保留上一份数据。

## 常见问题

**这个仓库和网站是什么关系？** 仓库是 [aiprice.io](https://aiprice.io/?ch=gh-data) 的每日数据存档，网站上是小时级实时数据，仓库是为了让人能拿到成批的、可对比的历史。

**为什么不给店铺名？** 只做价格统计，不做店铺背书；哪家店靠不靠谱需要单独判断，本站只负责把同一件商品的全网报价摆在一起。

**最低价能直接当成交价吗？** 不能。最低价往往是限量、无质保或需要自己处理售后的档位，下单前要看交付方式、质保期和库存状态。

**数据可以引用吗？** 可以，按 CC BY 4.0 转载，注明来源并链回 aiprice.io。

## 说明

本站只做价格比较与导航，不销售任何商品、不参与交易。价格与库存随时变化，以商家页面实际显示为准。
